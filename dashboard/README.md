# RansomWatch Dashboard

This React dashboard is part of the RansomWatch monitoring prototype. Its interface was generated with Lovable under the project owner's direction and AI-assisted coding. The dashboard reads from the local FastAPI service and can use mock data through VITE_RANSOMWATCH_DEMO_MODE=true.

See the repository root README for setup, API configuration, architecture, licensing, and limitations. Third-party component notices are in the root THIRD_PARTY_NOTICES.md.
